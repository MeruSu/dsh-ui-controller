# UI Controller · 界面控制器

**This is a placeholder release (0.0.1).** The package name is reserved and the
plugin is a no-op: installing it changes nothing in the UI.

Planned scope:

  - List every slot entry registered by every plugin, with its owner, priority and order.
  - Hide or reorder those entries from one page, without editing the other plugins.
  - Mirror a plugin entry into a different slot and forward clicks to the original.

Until then, nothing is registered and nothing is styled.

## Install

    dsh plugin --profile <profile> add dsh-ui-controller
